Six zones around the chassis. Each learns its vibration signature when you calibrate, and TouchMac tells you how well it can tell them apart.

How it works

Apple Silicon MacBooks hide a Bosch IMU on the Sensor Processing Unit. A desk tap shakes the chassis; TouchMac classifies which side got hit.

01

Sense

A small helper, installed once as a system service, reads the root-only sensor and streams it to the app over localhost — only while the app listens.

02

Detect

Onset detection watches dynamic acceleration. The threshold rises in noisy rooms, and taps while you type or click are ignored.

03

Match

k-NN against your calibration taps maps the signature to a zone — or rejects the hit if it is too ambiguous.

04

Act

Actions run in the user app, never as root. Errors and missing permissions show up in the activity log.

What you can assign

Every zone is two programmable buttons: a single tap and a double tap.

  • Open any app or website
  • Run a Shortcuts shortcut
  • Screenshot to clipboard
  • Volume up / down / mute
  • Play / Pause, next, previous
  • Mission Control, sleep display
  • Any shell command
  • Test mode (flash only)
  • Calibration accuracy score

Install

Two paths: grab the release binary, or build in under a minute with SwiftPM.

Binary release

  1. Download the latest .zip from GitHub Releases.
  2. Unzip, then clear Gatekeeper quarantine: 
    xattr -cr ~/Downloads/TouchMac.app
  3. Open the app. The welcome guide installs the sensor helper (admin password once — it then starts with your Mac).
  4. Calibrate the six zones (~10 taps each), assign actions, tap the desk.
Get the release

Build from source

git clone https://github.com/SuzalShrestha/touchmac.git
cd touchmac/app
sh make_app.sh
open build/TouchMac.app

Needs Xcode Command Line Tools. Full Xcode not required.

Will it work on my Mac?

ioreg -c AppleSPUHIDDevice -r -d1 | grep -c PrimaryUsage

Non-zero means the SPU IMU is exposed. The app also checks this on first launch. Intel Macs and some base M1 models do not have it.
